# 지형 단독 캡처 시범 비교

중국 서남부 32배. 앱 `2689f74ab5c759b5c8d5c8e3b045b59ab1e554b4`, 동일 데이터 핀과 실험용 192MiB 제한, Linux Chromium SwiftShader다. A1은 Actions 43179435577, 화면공간 D는 43178633881에서 따로 실행했다. 실제 뷰어의 최종 장면과 동일한 frameId의 지형 합성 직후 이미지를 저장했다. D에서 해당 화면공간 그리기 호출도 확인했다.

1280×752 이미지의 RGB 절대 차이는 채널당 평균 1.927, p95 7, 최댓값 50이며 세 채널 중 하나라도 2를 넘는 화소는 308,978개(32.10%)다. 지형 이외의 나중에 그리는 경계·수계·지명은 이 비교에 포함되지 않는다. 입력 PNG 해시는 각 원본 JSON의 frameCapture.terrainOnly.sha256에 기록돼 있다.

이것은 서로 다른 실행기의 단일 정지 프레임이고 A1은 1024 타일, D는 512 타일을 사용한다. 표시 및 비동기 상태 차이를 포함할 수 있으며 타일 크기와 화면공간 알고리즘의 효과를 분리할 수 없다. 같은 512 타일 방식과 추가 비교하기 전에는 특정 원인이나 화질 우열을 확정하지 않는다. 실제 GPU, 바다 경계, 지역별 또는 시간적 안정성을 입증하지 않는다.

## 같은 512 타일 크기의 추가 비교

B512 실행은 Actions 43182296112, 앱 `e01adf3752ba22e46fe34dfc92aed4f7ba0376c8`이며 D의 위 실행과 별도의 동일 유형 실행기다. 두 후보 모두 512 타일을 사용한다. 지형 단독 캡처의 RGB 채널당 평균 차이는 1.929, p95 7, 최댓값 50, 어느 한 채널이라도 2를 초과한 화소는 309,194개(32.12%)다. 타일 크기 차이만으로 앞선 차이를 설명할 수는 없다. 각각 별도 실행의 정지 프레임이므로 비동기 장면 상태나 지형 투영 차이 등 원인은 이 수치만으로 확정할 수 없다. 캡처 파일 해시는 B512 원본 JSON에 기록돼 있다.
