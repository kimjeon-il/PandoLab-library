기록일: 2026-11-12. 이 문서는 현재까지 완료된 제한적 실험의 결과이며 전체 비교 실험의 완료를 뜻하지 않는다. 운영 코드 반영, main 병합, 배포 및 자료 핀 변경은 하지 않았다.

## 현재 판단

실제 뷰어에서 A1/B/C를 한 번씩 실행해 타일과 승인된 GPU 프레임을 확보했지만 지명 Worker 오류, 화면 캡처 검증, D의 실제 뷰어 실행 및 세 번 이상의 교차 반복이 남아 최종 구조나 종합 점수를 결정할 수 없다. 추가 증거가 나오기 전의 보수적인 임시 판단은 현행 유지이다. COG는 현재 GitHub raw 호스트의 브라우저 `Content-Range` 노출 조건을 충족하지 못했다. 이것이 COG 자체의 기각이나 다른 호스트에 대한 판정은 아니다. E의 선행 조건은 충족되지 않았다.

## 재현 입력과 범위

NOAA 원본 SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`; 최초 P0 앱 `ddc6063e2ebc9dee87c6ef6c49038a0fe809c234`, 자료 핀 `921d86aa3c03ffa0b3d5879ad30c9914c4d1b31a`; 현재 실험 소스는 work/gis `21962e57b`에 있다. `p3/centered-*-input/`은 COG overview의 독립 원본 기반 입력이다. 1.58GB 원본은 진행 중인 후속 실험을 위해 기존 작업 캐시에 보존했다.

적어도 A1/B/C/D의 실제 뷰어 연결과 동일 품질·환경 비교, 화면 캡처, 네트워크·메모리·안정성·PC/모바일 시나리오, 하드 게이트 및 점수 평가가 남았다. SwiftShader 결과는 실제 GPU 성능이 아니다. 측정하지 못한 항목을 0이나 통과로 기록하지 않는다.

## 2026-11-12 후속: 비교 범위와 공통 예산

실제 Viewer 재실행 `43158642846`은 2×2 시험 자료의 가시 타일 누락과 1024 타일의 기본 96MiB 가시 예산 초과로 실패했다. 지명 Worker 15초 초과도 별도로 관측됐다. 원본 결과는 [뷰어 시험](p2/viewer-smoke/README.md)을 참조한다. 실패에서 기존 1배 화면을 32배 결과로 인정하지 않았다.

[확장 자료](p2/fixtures-coverage/README.md)는 세 지역의 보수적 가시 여유를 포함하며, [중국 COG](p3/coverage-china/README.md), [태국 COG](p3/coverage-thai/README.md), [네덜란드 COG](p3/coverage-netherlands/README.md)는 브라우저 복원 화소가 512·1024 참조 타일과 일치한다. 두 후보를 동일 상세도로 비교하는 별도 시험에는 후보 모두 같은 192MiB 가시 예산을 적용한다. 이는 실험 조건이며 기본 96MiB에서 발생한 상세도 하향을 지우거나 현행 운영 성능으로 취급하지 않는다. 실제 뷰어의 반복·상호작용·전체 화면과 지명 오류 및 Canvas 검증은 아직 완료되지 않았다.

현재 실험 코드 기준은 `work/gis` 앱 `d542cbb43`이다. 자료 표본은 자료 저장소 `11c1d4be35ec3d5aeab57393f2f947f6d810ad7d`, COG 표본은 `0fc425921e1fb431ef35d9af6f5ac762f2b3a269`의 고정 파일이다. 아래로 추가된 결과가 앞의 상태 표보다 최신이다.

## 추가 실제 프레임 결과

실행 `43163052092`에서 A1/B/C/D 모두 같은 중국 지역의 32배 Q1 지형 프레임을 얻었고 D도 기존 물리적 육지 스텐실을 사용해 실제 뷰어에서 그려졌다. A1과 C는 해당 단일 RGB 프레임이 같고, B는 최대 채널 차이 2다. D는 채널 차이 2 초과가 30.74%로 지형과 다른 계층을 분리한 원인 분석이 필요하다. 이 프레임들은 모두 지명 Worker 오류가 있었고 UI 캡처에 이전 지명 배치가 남아 G1–G3 통과나 성능 순위에 사용할 수 없다. 자세한 결과는 [뷰어 시험](p2/viewer-smoke/README.md)에 있다.

최신 실험 코드 `d710186d4`는 실험의 프로그램식 카메라 설정 뒤 라벨을 포함한 전체 뷰 무효화를 수행하고, 지명 요청 진단을 기록한다. 변경된 계측기의 실제 뷰어 재시험은 아직 진행 중이다. 기존 운영 코드와 운영 자료 핀, main과 배포는 변경하지 않았다.

## 진행 중간 보관: 자료·Worker·실기기

현행 Worker의 첫 RPC가 비동기 메타데이터 초기화 중 유실되는 문제를 실제 진입점과 Chromium에서 재현했고 `af1e9985e`에서 수신기 설치를 앞당겼다. 수정 후 A0 단독과 A0/A1/B/C/D 단일 화면 실행에서는 콘솔 시간 초과가 재현되지 않았다. 일부 지명 요청은 취소 기록이 있어 게시 완료 여부는 후속 진단 대상이다. 근거와 원본은 [뷰어 시험](p2/viewer-smoke/README.md)에 있다.

동일 화소의 512·1024 타일은 네 지역 표본에서 [파일 합계 약 0.9~1.1% 차이](p2/tile-size-regional/README.md)가 났으며 요청 수는 60 대 15다. 히말라야의 [타일](p2/fixtures-himalaya/README.md)과 [COG](p3/coverage-himalaya/README.md)도 원본·복원 해시를 검증했다. [GTX 1650 독립 실험](p3/screen-space-globe-gtx1650/README.md)은 뷰어가 아닌 정적 화면공간 시제품이며 동일 기기의 A1/B/C 비교가 아니다.

앱 `4e6e3aa55`로 중국 다섯 후보의 교차 3회 및 상호작용 측정 실행 `43170691547`이 진행 중이다. 이후 실험 코드 `77ba05ff7`에는 히말라야, 8/16/32배, 10초 이동·테마 왕복, 지형 단독 프레임과 장면별 캐시 기록이 추가됐지만 실제 Viewer에서 아직 전체 검증되지 않았다. 이 문서는 중간 기록이다. 세 지역 이상의 반복·전체 상호작용, 물리 GPU의 실제 뷰어, Canvas 및 하드 게이트 판정이 남아 있으므로 최종 점수와 구조 추천을 확정하지 않는다.
