# 지역별 확장 지형 실험 표본

원본 ETOPO 2022 30초 Float32 GeoTIFF SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`. 16배 가시 범위에 맞춰 태국 5×5, 히말라야 5×4, 네덜란드 6×4개의 1024 원본 블록을 선택했다. `webp/`는 해당 블록을 1024 또는 512 타일로 나눈 Q1 고도와 원본 기반 음영을 포함하며 345개 파일을 모두 무손실 복호화 검증했다.

독립 블록 간 공유 경계는 각각 40, 31, 38곳이고 모든 512 분할이 부모 블록과 정확히 일치한다. `gutter-verification.json` 참조. 각 COG는 원본에서 독립 샘플링한 세 해상도 단계를 보존하며 GDAL COG 검사 오류와 경고가 없다. Chromium의 로컬 range 서버를 사용한 각 `adapter-*.json`에서 1024·512 타일 전체의 복원 해시를 검증했다. 태국 표본의 32MiB PNG 캐시에서는 재읽기 시 일부 축출이 관찰됐다. 이는 제한된 시험이며 실제 외부 호스팅이나 사용자 전송량 측정이 아니다.

32배 화면 수용과 움직임을 포함한 실제 뷰어 검사는 별도다. 원본·운영 핀을 변경하지 않았다.
