# GTX 1650 독립 화면공간 시험

중국 남부 2×2 원본 기반 Q1 타일과 실제 물리적 육지 원본에서 별도 래스터화한 마스크를 사용하는 독립 WebGL2 페이지를 1280×800에서 세 번 실행했다. Chromium이 보고한 장치는 `ANGLE (NVIDIA, NVIDIA GeForce GTX 1650 ... Direct3D11)`이다. 각 반복은 300개 원시 rAF 간격을 `report.json`에 보존한다.

| 반복 | p50 ms | p95 ms | p99 ms |
|---|---:|---:|---:|
| 1 | 16.7 | 16.7 | 16.8 |
| 2 | 16.7 | 16.7 | 16.8 |
| 3 | 16.7 | 16.8 | 16.8 |

이는 단일 정적 셰이더 장면의 rAF 스케줄링 간격이지 GPU 실행 시간이나 뷰어 전체 프레임 시간은 아니다. 같은 장치의 A1/B/C 동등 조건 실측이 없고 날짜·이동·캐시·장애 복구도 포함하지 않는다. `globe-*.png`의 육지 마스크는 DEM 격자에 래스터화되어 해안 계단이 보이며 Viewer의 벡터 스텐실과 동등하다고 주장하지 않는다. 실기기 및 모바일 종합 하드 게이트 통과나 후보 순위에 사용할 수 없다.
