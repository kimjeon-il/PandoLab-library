# Canvas 높이 색상 조회 시제품

앱 `6ebf070fa` 실험 코드는 육지의 PCHIP 결과를 1m 간격 테이블에 기록하고 높이 보간 이후 테이블을 보간한다. 출력은 8비트 색상 근사이며 기본 Viewer에 연결하지 않았다. 2×2 합성 고도·음영과 라이트·다크에서 기존 정확한 CPU 색상과 각 RGB 차이 2 이내를 확인했지만 모든 고도·입력의 오차 한도나 해양·실제 화면 동등성을 입증한 것은 아니다.

1280×800 단일 육지 계층, Chromium headless/SwiftShader 단일 페이지 세 반복이다. 기존 색상 이미지 그리기와 1픽셀 readback은 109.3 / 10.5 / 8.3ms, 정확한 CPU 삼각형 수치 계산은 174.0 / 172.8 / 172.7ms, 조회 테이블 CPU 삼각형 계산은 91.3 / 82.1 / 81.6ms였다. 이전 방법의 putImageData는 별도로 0.4 / 0.3 / 0.4ms다. 테이블 구성 시간과 각 원본 수치는 `probe.json`에 있다.

초기 실행과 JIT의 영향, 데이터 분포 차이, 실제 마스크·지구본·다중 계층·Viewer·GPU 상황은 통제하지 않았다. 색상 이미지 생성은 그리기 측정에서 제외했다. 기존 방법보다 느리게 측정된 이 시제품을 기본 경로로 채택하지 않았다. 실제 Canvas와 대표 지역 검증은 미완료다.
