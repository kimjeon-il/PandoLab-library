# 대표 지역의 512·1024 타일 크기

동일한 ETOPO 원본의 각 지역 5×3 1024 블록을 1024 타일 15개 또는 512 타일 60개로 나타낸 Q1·원본 음영 무손실 WebP의 합계다. `comparison.json`은 원본·입력 매니페스트 해시와 원시 바이트 합계다. 매니페스트·HTTP 헤더와 캐시는 합계에서 제외했다. 경계 gutter와 모든 화소 일치는 각 표본 보고서에서 확인했다.

| 지역 | 512, 60개 bytes | 1024, 15개 bytes | 512 절감 |
|---|---:|---:|---:|
| 중국 서남부 | 12,983,100 | 13,117,034 | 1.02% |
| 태국 저지대 | 10,681,180 | 10,799,214 | 1.09% |
| 네덜란드 연안 | 9,137,226 | 9,226,328 | 0.97% |
| 히말라야 | 13,573,708 | 13,696,386 | 0.90% |

실측은 이 네 표본만을 대상으로 한다. 세계 전체 저장량·네트워크 전송량·요청 지연·브라우저 프레임 시간을 뜻하지 않는다. 더 많은 파일에 따른 요청·디코딩·캐시 비용은 별도 뷰어 비교가 필요하다.
