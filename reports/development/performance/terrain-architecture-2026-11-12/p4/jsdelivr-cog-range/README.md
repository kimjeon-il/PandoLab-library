# 공개 CDN의 고정 커밋 COG 범위 접근 실험

2026-11-12, Chromium 151.0.7922.34. GitHub 자료 저장소의 고정 커밋을 참조하는 jsDelivr 주소를 브라우저에서 직접 요청했다. 앱이나 운영 데이터 주소는 변경하지 않았다. 작은 표본과 큰 표본의 고정 주소·응답·시간은 각각 JSON에 있다.

9,250,897바이트 중국 2×2 COG는 표본 네 구간에서 HTTP 206과 JavaScript가 읽을 수 있는 Content-Range를 반환했고, 각 64KiB 구간 또는 마지막 구간은 지정된 SHA-256과 일치했다. 실제 COG 어댑터가 원격 범위 응답의 길이·범위·구간 해시를 검증해 1024 타일 4개와 512 타일 16개를 각각 원본 화소 해시와 일치하게 복원했다. 각 독립 어댑터 캐시 실행은 범위 요청 110개와 응답 본문 7,153,745바이트를 기록했다. 브라우저 네트워크 캐시를 분리하지 않았으므로 실제 회선 전송량이나 cold/warm 비교는 아니다. 시험 페이지는 로컬 HTTP origin이며 COG는 외부 CDN에서 읽었다.

30,117,542바이트 중국 5×4 COG는 403과 20MB 파일 제한 응답을 받았다. 현재 큰 표본을 이 주소에서 직접 스트리밍할 수 없으며, 제한 이내 독립 COG 분할에는 색상·경계·요청 수·성능·캐시 및 유지보수 비용을 추가 검증해야 한다. 이 단일 시점의 실험은 전체 파일·모든 CDN 경로의 안정성을 증명하지 않는다. jsDelivr의 [범위 응답 오프셋 오류 신고](https://github.com/jsdelivr/jsdelivr/issues/18679)도 있으므로 검증하지 않은 바이트를 수용하지 않는다. 실제 앱 Viewer 성능이나 호스팅 채택 결정은 아니다.

Fastly 전용 jsDelivr 주소에서도 같은 30,117,542바이트 COG의 범위 요청이 403과 20MB 제한을 반환했다. 이 추가 확인은 Node HTTP 요청이며 브라우저 CORS 검사가 아니다(`fastly-large-probe.json`).
