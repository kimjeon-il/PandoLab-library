# 네이티브 매크로 학습 캠페인 전환 기록

범위: Python 완전 전환의 부분 작업. 네이티브 배치·체크포인트 정본을 여러 epoch 실행기에 연결한 것이며, 전체 Python 학습기 전환이나 모델 승인을 뜻하지 않는다.

- 코드 커밋 `b5bc642a`. 배치 예산과 epoch 범위를 명시하고, 중단 후 코퍼스·체크포인트·설정·선택된 이전 epoch 영수증을 대조한다. 완료 epoch 중 학습 손실이 가장 낮은 후보를 기록하며, 독립 검증이나 배포 승인으로 표시하지 않는다.
- 선택한 실제 CIA 지도 한 장의 CPU 학습에서 기존 체크포인트를 이어받아 총 14개 타일의 첫 epoch를 완료했다. epoch 경계와 같은 epoch 내부에서 나누어 재개한 결과는 연속 실행과 모델 텐서 340개, optimizer 상태 32개, CPU 난수·샘플 순서·학습 상태가 일치했다. 이 결과는 학습용 계산 검증이다.
- 같은 보존 입력의 CUDA AMP 단일 배치도 기존 실행 경로와 모델 텐서 340개, optimizer 상태 32개, CPU/CUDA 난수·샘플 순서·상태가 일치했다. AMP 배율과 업데이트 및 건너뛰기 횟수도 같았다. CUDA 전체 epoch는 수행하지 않았다.
- 기존 입력 체크포인트는 optimizer가 없는 가중치 이행 후 만든 네이티브 체크포인트다. 이행 자체를 과거 optimizer의 정확한 재개로 표시하지 않는다. 선택은 학습 손실에만 근거하며 독립 검증, 검증 손실 기반 조기 중단, 모델 정확도 승인 및 배포는 수행하지 않았다.
- 관련 로컬 검사 5개와 [Windows/Linux 경량 계약 CI](https://github.com/kimjeon-il/Pando/actions/runs/41291706703)가 통과했다. 원본 지도와 기존 체크포인트는 변경하지 않았고 비공개 가중치는 이 보고서에 포함하지 않았다.

추가 코퍼스 및 독립 검증 연결과 기존 Python 학습·평가 호출자 종료가 남아 있다.
