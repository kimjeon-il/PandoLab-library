# 원본 RSFSR 쿠릴18컴포넌트의 섬 식별

기존1991-r1 폴리곤 component index에 대한 대조표이며, **1946 당시 정밀해안 검증이 아니다.** 날짜·주권은 별도 사건데이터에서 처리한다. 18컴포넌트는 원본에 들어있는 쿠릴 섬 전부라는 한정이며 실제 군도 전체를 빠짐없이 복원했다는 뜻이 아니다.

UW International Kuril Island Project의 북부·중부·남부 지도3장 모두 실제 다운로드하고 육안검수했다. 도판은 연구프로젝트2001 사이트 자료이며 기저지도 제작연도는 이번 미확인. 역사1946 원도로 취급하지 않는다. red labels는 섬 식별용, green circles는 고고학유적이며 경계점이 아니다. 저작물은 private 보존하고 공개 저장소 게시하지 않는다.

## 원본의 실제 생략 섬
대조목록·지도에는 있으나 원본1991폴리곤에서 해당위치 컴포넌트가 없는 섬: Antsiferov, Chirinkotan, Lovushki, Raikoke, Ushishir, Broutona, Chirpoi 본섬. Habomai는 Shibotsu 외 Polonskogo/Taraku, Tanfileva/Suisho, Yuri, Anuchina 등도 별도 컴포넌트 없음. 이들을 점·원형·임의폴리곤으로 대체하지 않는다. 소도서의 전체목록 완전성은 별도검토 대상.

## 해안 연대 차이
Smithsonian은 Matua1946 및2009 분화의 화쇄류가 바다에 도달했다고 기록한다. 따라서 기존 해안의 역사적 정점 동일성을 주장할 수 없다. Alaid도1933–34 해상화산체형성을 기록. whole-island 행정이동의 일반화 표시용 형상을 사용하는 것과 당년 측량해안을 확정하는 것은 구별한다.
