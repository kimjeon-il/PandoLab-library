## 방법과 결과

확대된 구면 지형의 Canvas Worker CPU 표본에서 타일의 구면 투영 그리기가 주요 비용임을 확인했다. 서로 인접한 셀이 공유하는 꼭짓점의 가시성과 투영을 타일 호출 범위에서 재사용한다. 실제 D3 구면 투영으로 전·후·전 순서로 각 6회 측정한 대표 타일은 40.61 → 13.77 → 39.06ms였고 4,050개 삼각형의 원본·대상 좌표 SHA-256이 일치했다. 지평선에 걸친 8,460개 삼각형도 완전히 일치했다. 이는 별도 타일 계산 측정이지 전체 화면의 개선율이 아니다. CPU 표본은 10초 동안 실행된 작업량이 다를 수 있어 이전과 이후의 표본 시간을 직접 개선율로 비교하지 않는다.

관련 단위 검사 30개, 린트, 웹 빌드가 통과했다. 실제 Canvas 물리 지형 검사는 변경 전 2회 실패 후 변경 후 통과했고, 화면 픽셀의 날짜 전환 전·후 값은 동일했다. 실제 확대 품질 검사는 변경 후 한 차례 실패하고 재실행에서 통과했다. Canvas 시간 전환 프레임 검사는 여전히 실패하여 미해결이다. Windows WebView2 검수 앱은 최종 Canvas 코드를 포함한 2bd0623da 빌드로 실제 실행해 읽기 전용·지도 준비·편집 차단을 확인했다.

## CI와 한계

단위 실행기의 공유 보고서·정리 테스트를 로컬과 CI에서 동일하게 격리했다. Hydro 교정·경계 검사에 누락된 네이티브 도구와 경로를 지정했다. 관련 실행기·선택기 검사는 30개, 실제 Windows Hydro 검사는 12개 통과, 1개는 OSGeo 런타임 부재로 건너뛰었다. 해당 변경의 Linux 실제 빌드 검증은 미완료다. 이전 Linux CI는 native Hydro 도구 누락, 보고서 잠금 충돌, Chromium 부재 외에도 지형·GPU·초기 표시 브라우저 오류가 있었으며 전체 통과가 아니다. GitHub 러너의 Microsoft apt 저장소 HTTP 403도 별도 환경 실패다.

Core 전후 측정과 파일 삭제 사고의 기록은 reports/development/performance/core-runtime-optimization-20261104를 참조한다. 이 보고서 첨부는 타일 좌표 비교, 두 Worker CPU 표본, Windows 실행 결과다.
