# 실제 뷰어의 평면 투영 제약

Actions 43188738896, 앱 `6142bd9131bb99724beccf0677b36c07085c05cb`. 실험 하네스에서 Viewer 화면을 평면으로 전환하려 했으나 `PL-PRODUCT-PROJECTION`, `The viewer supports only the globe projection.`으로 거부됐다. 실제 `src/app/product-mode-policy.js`는 제품 모드에 허용된 투영만 받아들이며, 현재 Viewer는 globe, editor는 flat이다. 첨부 명세의 평면·지구본 모두 실제 Viewer에서 비교하라는 전제와 최신 코드가 다르다.

제품 정책을 실험 목적으로 우회하거나 바꾸지 않았다. 따라서 이 실행은 평면 Viewer 화면이나 성능 증거가 아니다. 별도 시제품의 평면 역투영 및 합성 WebGL 픽셀 검사는 통과했지만 실제 편집기 화면·성능을 검증한 것은 아니다. 실제 편집기 기반 평면 비교는 별도의 실행 경로와 결과가 필요하다.

## 실험 전용 평면 시작 설정

정책은 실행 중 투영 전환을 막지만, 생성 시 선택한 투영을 고정한다. 현재 Viewer 구성은 시작값을 globe로 지정한다. 후속 실험은 제품 소스를 변경하지 않고 실험 라우트에서만 시작값을 flat으로 바꾸어 평면 시제품을 구동한다. 따라서 이것은 현행 공개 Viewer 기능의 실측이 아니다.

Actions 43192222022, 43193469142, 43195236174에서 초기 준비 대기 210초가 만료됐다. 마지막 두 실행의 타임아웃 이후 진단에서는 현재 flat 카메라, 국가·지도·지형 준비 및 2026-11 날짜, Viewer 준비 신호가 확인됐다. 제한 직전과 진단 시점 사이의 정확한 완료 순간은 기록되지 않아 지연 원인을 확정하지 않는다. `flat-bootstrap-failure-*.json`은 원본이다. 후속 측정기는 제한 시간 초과를 기록하고 같은 준비 조건을 짧게 재확인하며 조건이 충족되지 않으면 실패한다.
