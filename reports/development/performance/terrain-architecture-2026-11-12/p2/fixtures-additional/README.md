# 저지대·연안 뷰어 비교용 타일 표본

동일 NOAA Float32 원본의 태국 저지대와 네덜란드 연안에서 각각 기존 LOD5 1024 격자에 맞는 2×2 구역을 추출했다. Q1과 양자화 전 원본 기반 음영, 1픽셀 gutter를 사용한다. 각 지역의 1024 네 장과 512 열여섯 장, 총 40개 WebP를 복원 검증했고, 512 자료 32개가 해당 1024 자료의 gutter 포함 정확한 부분과 일치함을 확인했다.

원본 좌표·크기·해시는 `gutter-report.json`, WebP 해시는 `webp/manifest.json`에 있다. 이 자료는 대표 지역 실험 입력이며 실제 Viewer의 화면·성능 검증이나 전 세계 재생성이 아니다.
