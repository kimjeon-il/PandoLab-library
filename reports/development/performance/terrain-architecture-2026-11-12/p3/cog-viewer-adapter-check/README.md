# COG를 뷰어 타일 형식으로 변환하는 브라우저 검증

고정 COG의 각 64KiB 구간에 대해 HTTP 206·Content-Range·길이·SHA-256을 확인하고 geotiff.js로 해당 창을 복호화했다. 기존 뷰어의 이미지 타일 계약을 사용하기 위해 브라우저에서 PNG로 인코딩하며, 이 추가 비용은 실제 후보 측정에 포함해야 한다. 브라우저에서 1024 타일 네 장과 512 타일 열여섯 장 모두 1픽셀 gutter를 포함해 A1/B 참조 RGBA 해시와 일치했고, 범위 밖 타일은 거부했다.

전체 2×2 지역의 1024 타일을 읽는 경우 93개 범위·6,063,399바이트, 512 타일을 읽는 경우 87개 범위·5,680,666바이트였다. 로컬 동일 출처와 64KiB 청크 캐시에서 전체 구역을 읽은 단일 기능 시험이며, 실제 CDN 전송량이나 렉 비교가 아니다. 각 경우 동일 타일 재사용을 한 번 확인했다. `report.json`에 파일별 해시와 원시 수치가 있다.
