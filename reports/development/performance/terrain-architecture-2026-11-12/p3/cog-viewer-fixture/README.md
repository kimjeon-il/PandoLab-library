# 뷰어 비교용 정렬 COG 표본

중국 서남부 2×2 타일 구역과 바깥 4픽셀 여유를 포함한 2056×2056 Q1 COG이다. 원본 Float32에서 각 단계별로 별도 평균해 읽은 2056·1028·514 표본을 본판과 overview로 저장했다. GDAL 구조 검사(full_check)에서 오류·경고는 없었고, 전 단계와 전 채널은 입력과 일치했다. 생성 시 GDAL_DATA 환경 미설정 경고가 한 차례 발생했다. SHA-256, 청크별 해시, 구조 검사 결과는 `manifest.json`에 있다.

LOD5의 1024 타일 네 개와 각각의 gutter를 별도 생성한 기존 참조와 바이트 단위로 대조했다. 생성 파일 7,001,869바이트와 압축 입력 원본은 실험 증거이며 운영 자료가 아니다.
