마지막 단일 반복의 정착 대기 시간은 각각 46,369ms와 76,841ms였고 rAF p95는 18ms와 3,191ms였다. 동작·정착을 포함한 SwiftShader 측정으로 변동이 클 수 있으며, 각 구성에 한 번씩만 실행해 성능 순위나 개선율을 결정할 수 없다. 실제 화면 캡처, 세 번 이상 교차 반복, 이동·날짜·테마·다른 지역, Canvas, 비교 대상 C·D와 원격 호스트 검증이 남았다.

`attempt-6`의 실제 WebGL 프레임을 A1 기준으로 비교하면, 512와 COG 각각에서 RGB 채널 차이가 2를 넘는 화소는 1,453개/962,560개(약 0.151%)이고 그 위치는 x=0~272, y=135~406이다. 평균 채널 차이는 각각 약 0.0415와 0.0410, 최대 차이는 112다. `pixel-comparison.json`에 캡처별 SHA와 수치가 있다. 한 시점의 전체 장면 비교이므로 비동기 수계 등 다른 계층도 차이에 기여할 수 있고, 원인과 해안·시간별 동등성은 아직 판정하지 않았다. 전체 페이지 캡처는 게시된 GPU 프레임과 다를 수 있어 별도로 검증해야 한다.

## 일곱 번째 실제 뷰어 시험: 선택 정책과 시험 영역 불일치

GitHub Actions `43158642846`, 앱 `21962e57b6eca26470a434a28353e524c539688d`, 중국 서남부 32배 실험의 원본은 `attempt-7/`에 보존했다. 네 후보 모두 180초 대기 후 실패했다. A1과 COG는 1,024 타일의 실제 LOD 5 가시 후보 8장이 96MiB 수치 DEM 가시 예산을 넘어 LOD 4로 내려갔으나, 계측기는 LOD 5를 기다렸다. 512 타일 후보 B와 D는 LOD 5에서 17장을 요구했으나 2×2 원본 블록으로 준비한 16장에는 세 요청이 포함되지 않아 14장만 준비되고 지형 오류가 발생했다. 기존 화면 샘플 격자 검사만으로 뷰어의 보수적 가시 여유까지 확인한 것은 아니었다. 네 후보에 지명 Worker 15초 초과도 기록되었으며 원인은 별도로 확인해야 한다. 이번 결과는 후보 성능 또는 우열의 증거가 아니다.

## 여덟 번째 실제 뷰어 시험: 네 후보 프레임 확보, 지명 오류로 실패

GitHub Actions `43163052092`, 앱 `d542cbb4353db83b2b00c187d14d7ae789095f7a`, 중국 서남부 32배, 후보 공통 실험 가시 예산 192MiB의 원본은 `attempt-8/`에 보존했다. A1, B, C, D 모두 LOD5 지형 준비 및 GPU 프레임을 확보했다. 화면공간 D는 실제 Viewer 스텐실 패스에서 20회 그렸고 atlas 1회를 생성했다. 이 수치는 단일 실행의 기록이며 세 번 반복한 성능 비교나 실기기 GPU 결과가 아니다.

네 후보 모두 지명 Worker가 15초를 초과해 `PL-PLACE-LOAD-001`이 발생하여 실패했다. 페이지 캡처는 GPU 지형 화면과 높은 비율로 일치했으나 직접 살펴보면 세계 화면의 지명·국가명이 확대 지형 위에 남았다. 시험 카메라 설정은 `setViewState` 후 GPU 프레임만 무효화했으며 전체 라벨 재배치를 요청하지 않았다. 이 호출 경로는 올바른 지도 상호작용 대체가 아니므로 이전 캡처들의 UI 정합성 판정에도 주의한다. 새 실험기는 동일한 프로그램 카메라 설정 후 Viewer의 전체 뷰 무효화를 요청하도록 바꾸고, 지명 요청 진단과 실제 화면을 다시 확인한다. 이 수정은 실험 경로에만 적용하며 지명 Worker 시간 초과의 원인은 별도 조사 중이다.

동일 시험의 승인된 1280×752 GPU 프레임 단발 비교(`attempt-8/framebuffer-diff.json`)에서 A1과 COG는 전체 RGB가 완전히 같고 512 타일은 채널당 최대 차이 2였다. D는 채널 차이 2 초과 화소가 295,919/962,560(30.74%), 채널 차이 평균 1.84, 최대 50이었다. 모든 차이를 지형 탓으로 확정할 수 없고, 별도 레이어의 비동기 변동이 포함될 수 있어 반복 및 지형 단독 검증이 필요하다. G2 통과를 뜻하지 않는다.

B와 D 프레임을 x/y 각각 -2~2 정수 화소로 옮겨 같은 안쪽 영역의 평균 RGB 절대 차이를 계산했다(`attempt-8/integer-shift-analysis.json`). 최솟값은 이동 없음 1.842이며 다음은 y=+1에서 6.343이었다. 정수 화소 단위의 전체 화면 이동은 관찰된 차이를 설명하지 못한다. 이는 0.5화소 미만 차이, 지구본 격자 투영 근사 및 다른 계층 영향 여부를 판별하지는 못한다.

추가 확인: 여덟 번째 실행의 사전 가시 개수는 첫 프레임 축척을 그대로 32배 해 계산해 실제보다 작게 잡혔다. 시작 `globeZoom`이 1.25였고 최초 scale은 412.9125이므로 올바른 32배 scale은 10570.56이다. 실제 Viewer는 1024 타일 8장과 512 타일 17장을 요청했다. 예비 계산기는 시작 확대를 반영하고 완료 프레임의 실제 축척을 별도 대조하도록 수정했다. 여덟 번째 실행의 프레임 자체를 사전 검사 통과 근거로 간주하지 않는다.

## 아홉 번째 실제 뷰어 시험: 라벨 위치 갱신, Worker 지연

실행 `43164883720`, 앱 `d710186d488518920ea35b562f3efc5f5a77228d`의 원본은 `attempt-9/`에 있다. 네 후보 모두 중국의 32배 지형과 실제 GPU 프레임을 얻었으며 각 화면의 지형 캡처와 GPU 프레임이 높은 비율로 일치했다. 이전 세계 지명이 확대 장면에 남아 있지는 않았지만 15초 지명 Worker 오류는 네 후보 모두 남아 전체 실행은 실패했다. 이 실행의 사전 축척 계산은 초기 1.25배를 반영하지 못했고, 라벨 위치 갱신에 사용한 `invalidateView`는 정착 단계의 전체 라벨 재배치를 뜻하지 않는다. 후속 코드는 실제 초기 배율과 `view-settle`을 사용한다.

기록된 일부 로컬 지명 manifest와 shard는 네트워크 시작 후 수 밀리초에 응답했다. 최초 urban-lifetimes 요청에서 manifest 요청 시작까지 약 15~16초가 지난 사례가 있어 전송 자체보다는 요청 시작 전 Worker 경로가 지연됐을 가능성을 확인할 필요가 있다. 이는 원인 확정이 아니며 중단된 요청 및 이후 재시도와의 시간 순서도 추가 계측이 필요하다. D의 atlas는 6회 생성돼 재사용 및 프레임 전환 비용도 후속 반복에서 확인해야 한다.

## 열 번째 실제 뷰어 시험과 Worker 첫 요청 결함

실행 `43166393876`, 앱 `1b400ac6dc4a3c53cd534a7585dae91b5dbfb262`의 원본은 `attempt-10/`에 있다. 실제 초기 globeZoom 1.25를 반영한 32배 scale 예측 10570.56이 완료 GPU 프레임과 일치했고, 가시 타일은 1024 8장·512 17장으로 모두 표본 범위에 있었다. 네 후보의 실제 지형 프레임을 얻었지만 지명 Worker 15초 오류가 계속되어 실패했다.

A1 실행에서 지명 Worker 스크립트는 06:12:55.783 UTC에 요청돼 약 15ms에 응답했으나 지명 처리 모듈의 요청은 06:13:13.746 UTC에 시작됐다. 다른 후보도 유사했다. 실제 지명 Worker 진입점과 실제 RPC host를 로컬 Chromium에서 실행하고 build-meta 응답을 250ms 늦추는 합성 재현에서, 기존 코드는 시작 즉시 전송한 첫 RPC를 잃었고 1.5초 후 실패했다. Worker의 top-level `await import(build-meta)`가 끝난 뒤에야 RPC 수신기를 설치하는 구조가 원인이다. `af1e9985e`는 메타데이터 로딩을 첫 요청 처리 안으로 옮겨 수신기를 동기 설치했고, 같은 회귀는 통과했다. 실제 Viewer 및 GitHub Actions에서 오류가 없어졌는지는 후속 실행으로 확인해야 한다.

## Worker 수정 후 A0 단독 시험

실행 `43168349616`, 앱 `af1e9985edf6b286da4fe3e97296a5f05897b660`의 원본은 `a0-after-worker-fix/`에 있다. 현행 DEM 0.14.0과 96MiB 정책으로 중국 32배 장면을 한 번 실행했고 322개 프레임 간격과 실제 캡처를 얻었다. 콘솔 예외 및 지명 Worker 시간 초과는 기록되지 않아 단독 실행은 통과했다. Worker 처리 모듈은 Worker 생성 직후 요청됐다. 일부 지명 manifest·shard 요청은 `ERR_ABORTED`로 기록돼 취소 사유와 지명 표시 완료는 별도 확인이 필요하다. 단일 SwiftShader 기록이며 지형 후보의 비교 성능이나 GTX 1650 실측이 아니다.
