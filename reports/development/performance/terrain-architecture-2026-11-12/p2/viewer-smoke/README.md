동일한 Q1 고도·원본 기반 음영과 PCHIP 실험 셰이더를 Playwright 요청 가로채기를 통해 실제 Viewer에 제공했다. 프로젝트·운영 자료와 정식 셰이더는 변경하지 않았다. 1,024 타일 네 장과 512 타일 열여섯 장의 입력은 서로 동일하고 1픽셀 gutter도 일치한다. 시험 지역 이외의 LOD5 타일은 제공하지 않고 실패 처리하며, 시작과 저배율 단계는 기존 v0.14 자료를 사용하는 **지역 한정 혼합 시험**이다.

마지막 단일 반복의 정착 대기 시간은 각각 46,369ms와 76,841ms였고 rAF p95는 18ms와 3,191ms였다. 동작·정착을 포함한 SwiftShader 측정으로 변동이 클 수 있으며, 각 구성에 한 번씩만 실행해 성능 순위나 개선율을 결정할 수 없다. 실제 화면 캡처, 세 번 이상 교차 반복, 이동·날짜·테마·다른 지역, Canvas, 비교 대상 C·D와 원격 호스트 검증이 남았다.

`attempt-6`의 실제 WebGL 프레임을 A1 기준으로 비교하면, 512와 COG 각각에서 RGB 채널 차이가 2를 넘는 화소는 1,453개/962,560개(약 0.151%)이고 그 위치는 x=0~272, y=135~406이다. 평균 채널 차이는 각각 약 0.0415와 0.0410, 최대 차이는 112다. `pixel-comparison.json`에 캡처별 SHA와 수치가 있다. 한 시점의 전체 장면 비교이므로 비동기 수계 등 다른 계층도 차이에 기여할 수 있고, 원인과 해안·시간별 동등성은 아직 판정하지 않았다. 전체 페이지 캡처는 게시된 GPU 프레임과 다를 수 있어 별도로 검증해야 한다.

## 일곱 번째 실제 뷰어 시험: 선택 정책과 시험 영역 불일치

GitHub Actions `43158642846`, 앱 `21962e57b6eca26470a434a28353e524c539688d`, 중국 서남부 32배 실험의 원본은 `attempt-7/`에 보존했다. 네 후보 모두 180초 대기 후 실패했다. A1과 COG는 1,024 타일의 실제 LOD 5 가시 후보 8장이 96MiB 수치 DEM 가시 예산을 넘어 LOD 4로 내려갔으나, 계측기는 LOD 5를 기다렸다. 512 타일 후보 B와 D는 LOD 5에서 17장을 요구했으나 2×2 원본 블록으로 준비한 16장에는 세 요청이 포함되지 않아 14장만 준비되고 지형 오류가 발생했다. 기존 화면 샘플 격자 검사만으로 뷰어의 보수적 가시 여유까지 확인한 것은 아니었다. 네 후보에 지명 Worker 15초 초과도 기록되었으며 원인은 별도로 확인해야 한다. 이번 결과는 후보 성능 또는 우열의 증거가 아니다.
