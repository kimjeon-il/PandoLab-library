# 중국 서남부 5×4 지형 실험 표본

원본 ETOPO 2022 30초 Float32 GeoTIFF SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`. 16배에서 기존 5×3 표본 밖의 LOD5 타일 2개를 요구해 실패한 실행 43183013224를 재현 범위에 포함하기 위해 북쪽 한 행을 확장했다. 세계 전체 자료가 아닌 중국의 5×4 1024 원본 블록이다.

`webp/`의 1024 타일 20개와 512 타일 80개는 Q1 높이와 양자화 전 Float32에서 구한 음영을 담으며, 무손실 인코딩 후 모두 디코딩해 원시 바이트 일치를 확인했다. `gutter-verification.json`은 20개 블록과 80개 분할, 블록 간 공유 경계 31개의 정확한 일치를 기록한다.

`cog/`는 같은 원본에서 각 LOD를 독립 생성한 3단계 COG다. GDAL COG 전체 구조 검사는 경고와 오류가 없었고, `cog-adapter-check.json`은 Chromium에서 1024 및 512 타일 전부를 COG에서 복원해 원시 해시와 일치시킨 결과다. 실험용 로컬 range 서버를 사용했으며 공개 호스트의 CORS나 외부 망 성능을 입증하지 않는다. 자료는 대표 지역의 실험 표본이며 운영 자료 핀을 변경하지 않는다.
