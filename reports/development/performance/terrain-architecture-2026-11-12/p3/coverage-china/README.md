# 확대 지역 COG 복원 검증

동일 ETOPO 원본에서 5×3 타일 영역과 마진을 세 해상도로 별도 표본화해 COG overview를 구성했다. `manifest.json`에 자료 해시와 64KiB 청크별 해시가 있으며, `pyramid-input.json`은 각 해상도의 원본 기반 입력 해시다. GDAL 전체 COG 구조 검사에서 오류·경고는 없었다. GDAL 실행 시 `GDAL_DATA`가 설정되지 않아 `tms_NZTM2000.json`을 찾지 못한다는 별도 환경 경고가 출력됐다.

`report.json`은 브라우저에서 같은 지역의 1024 타일 15개와 512 타일 60개를 COG 부분 요청으로 복원하여 모든 RGBA 픽셀과 gutter 해시를 기존 타일에 대조한 결과다. 요청은 로컬 모의 206 서버로 처리했으므로 공개 호스트 접근성이나 실제 전송량의 증거는 아니다. 최종 뷰어 성능 비교는 별도다.
