# 동시 COG 타일 요청의 중복 범위 공유

실제 Viewer 예비 시험에서 여러 타일이 동시에 같은 COG 청크를 요청해 7,001,869바이트 파일에서 9,549,928바이트의 범위 응답이 전송되는 중복을 관찰했다. 검증된 청크 캐시에 더해 진행 중인 같은 청크 요청을 공유하고, 한 소비자의 취소가 다른 소비자를 중단하지 않도록 변경했다. 모든 소비자가 취소하면 해당 요청을 중지하고 다음 재시도를 허용한다.

동일 로컬 브라우저 기능 시험에서 1024 타일 4개와 512 타일 16개를 각각 동시에 요청해 전 타일의 gutter 포함 RGBA가 참조와 일치했다. 각 경우 네트워크는 82요청·5,363,469바이트였고 진행 중인 요청 재사용은 각각 65회와 204회였다. 같은 타일 재사용과 지역 밖 거부도 확인했다. `report.json`에 전체 결과가 있다. 이전 순차 호출 시험과 요청 방식이 달라 이 수치를 성능 개선율로 비교하지 않는다.
