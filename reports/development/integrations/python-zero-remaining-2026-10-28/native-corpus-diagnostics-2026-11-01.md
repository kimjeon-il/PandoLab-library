# 학습 코퍼스 네이티브 진단 전환 기록

범위: Python 완전 전환의 부분 작업. 기존 네이티브 단일 지도 진단을 코퍼스별로 순차 호출하며, 학습 모델의 정확도 승인이나 배포를 뜻하지 않는다.

- 코드 커밋: `d398f098`, 동일 입력·출력 텐서 기록 `18ec7e80`. 입력 코퍼스와 체크포인트, 영수증의 해시 일관성을 확인하며 기존 출력과 취소를 보호한다. 보고서는 학습 전용이고 독립 평가·배포 승인이 아님을 명시한다.
- 보존된 CIA 세계 지도 한 장과 CPU 체크포인트로 코퍼스 진단을 실행했다. 선택 타일은 원본 픽셀 `[1344, 448]`이며 채널별 결과와 JPEG 바이트는 기존 네이티브 단일 지도 진단과 일치했다. 미리보기 0개 옵션도 확인했다.
- CIA 세계 지도와 캐나다 국가 지도 두 장도 보존된 CUDA 체크포인트로 순차 처리했다. 두 결과가 같은 코퍼스·체크포인트를 가리키고, 미리보기 1개 제한이 적용됨을 확인했다. 이는 학습 입력 진단이다.
- 같은 체크포인트를 C++로 ONNX opset 17에 내보내 동일 입력으로 Node WASM 및 헤드리스 브라우저 WASM을 실행했다. 출력 형상은 `1×7×512×512`, 최대 절대오차는 두 환경 모두 `0.0001888275146484375`로 기준 `0.005` 이내다. 이는 단일 타일의 실행 동등성으로, 학습 정확도나 독립 평가가 아니다.
- 코드 커밋 `38b09bde`는 명시적 요청에 따라 C++ ONNX 파일과 연결된 후보 manifest를 만든다. 체크포인트 영수증의 기존 optimizer 없는 가중치 이행, 계보 미완료 및 미승인 상태를 유지하고 기존 출력을 보호한다. 실제 CPU 체크포인트에서 생성한 모델과 manifest로 Node WASM 일치를 다시 확인했고, [Windows/Linux manifest 계약 CI](https://github.com/kimjeon-il/Pando/actions/runs/41290738332)도 통과했다.
- 로컬 진단 검사 5개와 내보내기 검사 6개가 통과했다. 기존 지도 미리보기 CI에서 안내 문구 변경을 반영하지 못한 테스트를 발견해 지도 픽셀과 현재 문구를 각각 검사하도록 수정했다. [Windows/Linux 관련 CI](https://github.com/kimjeon-il/Pando/actions/runs/41290306581)가 수정 후 통과했다.
- 코드 커밋 `e78a2437`은 출판 자료의 기존 생성기 식별값을 Git 이력의 원본과 대조해 고정했다. Python 생성기 파일을 읽을 수 없어도 기존 생성기 해시, 출처 및 권리 검사가 동작하며, 관련 로컬 검사 7개가 통과했다. 출판 생성기 자체의 전환 완료를 뜻하지 않는다.

기존 Python 진단기의 전체 입출력·호출자 대체와 독립 평가가 남아 있다. 비공개 모델·가중치나 원본 지도는 이 보고서에 게시하지 않았다.
