# 동일 영역 WebP 타일 크기 예비 시험

위 P1과 동일 원본 SHA-256, Q1 양자화, 원본 기반 음영으로 1,024×1,024 대표 영역 세 곳을 만들었다. 같은 화소를 512×512 네 장 또는 1,024×1,024 한 장으로 lossless WebP 인코딩하고, 각각 복원된 화소가 입력과 동일함을 확인했다.

| 지역 | 512 네 장 합계 (bytes) | 1,024 한 장 (bytes) |
|---|---:|---:|
| 태국 저지대 | 744,738 | 749,550 |
| 중국 서남부 | 1,468,092 | 1,478,128 |
| 네덜란드 연안 | 338,462 | 344,826 |

원본 압축 표본과 `tiles/tiles-report.json`에는 지역별 파일의 해시, 크기 및 단회 로컬 GDAL 처리 시간이 있다. 타일 halo, 화면 가시 영역 경계, HTTP 요청·캐시, 브라우저 디코딩 및 GPU 업로드를 포함하지 않는다. 따라서 이 결과는 B의 유효성, 렉 개선, 최종 타일 크기나 전 세계 저장량을 결정하는 근거가 아니다.
