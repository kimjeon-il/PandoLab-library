# 구면 타일 격자의 투영 근사 오차 표본

중국 중심 `[102,28]`, 화면 축척 10570.56, 512 타일 `5/66-14`. 앱 `src/rendering/gpu-terrain-preparation.js`의 구면 격자 간격 공식과 두 삼각형의 보간을 재현하고, 각 격자 셀의 균일한 17×17 경위도 점을 정확한 직교 투영과 비교했다. 원본 계산 코드는 `globe-grid-error.mjs`, 결과는 `globe-grid-error.json`이다. 각 셀 경계의 점은 중복될 수 있다.

격자 4×4, 표본 4,624점의 화면 좌표 차이는 p50 0.188px, p95 0.413px, 최대 0.525px이다. 이는 이 타일 전체의 균일한 지리 표본을 이용한 계산이며 일부 점은 실제 1280×752 화면 밖이다. 픽셀 색상 차이, 캡처의 비동기 상태 또는 다른 지역·확대에서의 최대 오차를 직접 측정한 것은 아니다. 기존 타일과 역투영 시제품의 화면 차이에 기여할 수 있는 기하학적 요인을 보여 주며, 원인이나 어느 쪽의 체감 화질이 더 좋은지는 확정하지 않는다.
