# Canvas 수치 삼각형 렌더링 예비 비용

앱 `c3961e2eb`의 실험 전용 래스터는 1026×1026 합성 원본을 1280×800 화면의 두 삼각형으로 그리면서 각 화면 화소의 고도와 음영을 보간하고 PCHIP 색상을 적용한다. 생산 Viewer에는 연결하지 않았다. Chromium headless/SwiftShader, 단일 계층, 동일 페이지에서 세 차례 실행했다. 전체 원본은 `probe.json`에 있다.

| 측정 | 1회 | 2회 | 3회 |
|---|---:|---:|---:|
| 기존 방식의 색상 이미지 drawImage 및 한 화소 readback (ms) | 154.2 | 12.4 | 9.7 |
| CPU 수치 삼각형 raster (ms) | 146.0 | 133.4 | 141.0 |
| 수치 결과 putImageData (ms) | 0.4 | 0.3 | 0.3 |

그림 준비, 물리적 육지 마스크, 지구본 다수 삼각형, 다중 계층, 실제 Viewer와 실 GPU는 포함하지 않는다. drawImage 첫 실행은 큰 초기 지연이 있었고 매 반복은 같은 페이지를 재사용했다. 기존 이미지 색상 준비 시간도 표에는 포함하지 않는다. 따라서 실제 제품 p95나 전체 렌더러 비교가 아니다. 다만 수치 CPU 계산 자체가 한 화면 한 계층에서 133ms 이상이어서 이 구현을 현재 기본 경로로 즉시 채택하는 것은 적합하지 않다. 더 빠른 방법과 실제 Viewer 검증이 필요하다.

단위 검사에서는 화면 범위·삼각형 바깥 투명도와 고도 선보간 후 색상 결과를 확인했다. 사용자에게 요청된 Canvas 화면 연결과 대표 지역 실화면 검증은 아직 완료되지 않았다.
