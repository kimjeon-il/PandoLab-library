# 중국 서남부 뷰어 교차 반복 실험

실행: GitHub Actions 43170691547, 앱 `4e6e3aa55f709c64d35dbed3c871e2f48f79ec5c`, 자료 핀 `921d86aa3c03ffa0b3d5879ad30c9914c4d1b31a`. 1280×800 Chromium의 Linux SwiftShader, 동일 실행기에서 후보별 새 브라우저를 사용했다. 원본 `report.json`, 계산된 `summary.json`, 각 장면의 실제 화면과 프레임버퍼 캡처를 함께 보존한다.

A0, A1, B512, COG, 화면공간 D를 순서 교차하여 각각 3회 측정했다. 32배와 drag, rotate, previous-year, date-return, dark, light, warm-return 일곱 장면에서 각 반복당 최소 300개 프레임 간격을 기록했으며 실행 상태는 모두 통과했다. 콘솔 및 자료 경로 오류는 보고되지 않았다. 초기 지명 스냅샷 142개와 지역 이동 후 0개가 기록됐으나, 이 숫자만으로 지역 지명의 정상 여부를 판단할 수 없다.

수치는 반복별 백분위의 중앙값이며 세 번의 표본으로 신뢰구간을 주장하지 않는다. 프레임 간격은 준비와 대기를 포함하는 requestAnimationFrame 일정의 관측치로, GPU 표시 시간이나 순수 조작 시간은 아니다. 준비 시간은 지형 외 장면 계층을 포함한다. PSS는 브라우저 프로세스 계열 전체 값이며 GPU VRAM이 아니다. 각 조작은 짧은 동작 후 대기 구간을 포함하므로 일곱 장면의 백분위는 대기 프레임이 지배할 수 있다.

A0은 현재 자료와 96MiB 제한을 사용하고, 나머지는 표본 Q1 자료와 실험 전용 192MiB 제한을 사용한다. A0은 화면 상세도가 다를 수 있고 동일한 인메모리 프록시를 쓰지 않는다. 후보들은 LOD5 표본만 동일하며 낮은 LOD는 기존 자료다. COG와 타일은 실행 전에 검증하고 메모리에서 제공했으므로 실제 외부 호스팅의 지연이나 전송량이 아니다. 이 결과로 후보 순위나 실제 하드웨어 성능을 확정하지 않는다.

이 실행에는 8·16배, 10초 연속 이동, 10회 테마 전환, 지형 표시 방식 변경, 지형 단독 캡처가 없다. 다른 지역, 실제 GPU 및 Canvas, 외부 COG 서버도 검증하지 않았다. 후속 실험과 하드 게이트가 필요하다.
