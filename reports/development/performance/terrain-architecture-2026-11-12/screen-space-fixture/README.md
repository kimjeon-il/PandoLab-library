# 화면공간 GPU 단일 표본 타당성 시험

중국 서남부 Q1 1,024×1,024 WebP 표본(`SHA-256 7fe9fd6f41139faa5fde8f37f7747c8968fae9ca23ab49c5fa6e4d73992c1484`)을 Chromium 151/WebGL2의 한 화면 삼각형으로 표시했다. 4개 고도 값을 각각 복호화한 후 이중 선형 보간하며, PCHIP 육지 팔레트는 4,096항목 8bit LUT로 근사하고 원본 기반 음영을 곱한다. 실제 캡처 세 장과 300개 연속 rAF 간격을 각 반복마다 보관했다. 화면은 독립 실험 장면이며 Pando Viewer 캡처가 아니다.

Windows, 1,280×800, DPR 1, ANGLE Vulkan SwiftShader에서 세 반복의 p50/p95/p99는 각각 16.7/16.7/16.8ms, 16.7/16.8/16.8ms, 16.7/16.7/16.8ms였다. 수치는 `report.json` 원본 배열에서 산출했으며 디스플레이 프레임 동기화 영향을 받는 rAF 스케줄 간격이지 GPU 실행 시간이나 실제 표시 FPS가 아니다. P7은 다른 기기·장면·코드를 사용하므로 이 수치와 직접 비교하거나 D의 우위를 주장할 수 없다.

이 코드는 단일 사각형 타당성 확인에 그친다. 평면·지구본 역투영, 타일 탐색·누락, 육지 마스크·바다 팔레트, Viewer의 선택·날짜·테마, Canvas 대체 및 실제 지도 성능이 없어 명세의 D 후보 완성이 아니다. 따라서 하드 게이트를 통과한 D로 간주하거나 E를 시험하지 않았다.
