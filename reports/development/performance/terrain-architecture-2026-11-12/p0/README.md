## 코드 책임과 비용 가설

- WebGL: 공유 가시 타일 선택 → 제한된 fetch/디코딩 큐 → 타일별 GPU 텍스처와 투영 격자 메시 → 화면 합성. 타일마다 텍스처와 메시가 있으나 실제 병목 여부는 추가 계측이 필요하다. 디코딩 대기 상한 32MiB, 지형 캐시 기본 목표 128MiB는 정책값이다.
- Canvas: 같은 선택 정책에서 원본 DEM과 육지·바다·흑백 RGBA 색상 평면을 만들고 캐시한다. 라이트/다크 전환 시 원본 재다운로드 없이 색상 평면을 다시 만든다. 이 설명은 구현 확인이지 실측 메모리 증가나 렉의 원인 확정이 아니다.
- 물리적 육지 마스크는 고도 부호와 별개다. WebGL은 현재 고도 텍셀별 색상 계산 후 색상을 보간하며, 실험 명세의 고도 보간 후 PCHIP와 같지 않다.
