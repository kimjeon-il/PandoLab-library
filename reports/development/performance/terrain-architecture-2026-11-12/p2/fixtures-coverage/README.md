# 보수적 가시 범위를 포함한 지형 표본

ETOPO 원본 SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`에서 세 지역 각각 1024 타일 5×3을 생성했다. 각 영역을 동일한 512 타일 60개로도 분할했다. 모두 무손실 WebP로 왕복 대조했으며, `verification.json`에는 지역별 타일 간 22개 공유 경계와 60개 분할 결과의 정확 일치가 기록되어 있다.

이 범위는 고정된 32배 장면의 Viewer 보수적 가시 타일 목록을 포함한다. 해당 타일들이 모두 보일 정도의 96MiB 기본 수치 DEM 예산이 보장된다는 뜻은 아니다. 장면 이동과 회전 시의 화면 범위 및 실제 뷰어 게시는 별도 검사 대상이다. 기존 2×2 자료의 결함과 그 실패 실행은 `../viewer-smoke/README.md`에 남겼다.

## 실제 선택 정책 계산

`admission-model.json`은 Viewer의 동일한 보수적 가시 선택과 12바이트/화소 추정 예산으로 계산한 값이며 실측 메모리가 아니다. 1280×752, 지구본 scale 10570.56에서 1024 타일은 중국 8장(96.38MiB), 태국 7장(84.33MiB), 네덜란드 12장(144.56MiB)을 요구한다. 512 타일은 각각 17장(51.40MiB), 16장(48.38MiB), 25장(75.59MiB)이다. 모두 확장 표본에 있다. 기존 96MiB 정책은 중국과 네덜란드의 1024 타일을 LOD 4로 낮춘다. 192MiB 공통 실험값은 최대 계산치 144.56MiB와 여유를 포함하기 위한 조건이며 실제 메모리 상한 또는 제품 설정 변경 승인이 아니다. 장면 이동 중에도 이 예산을 충족하는지는 별도 실측한다.
