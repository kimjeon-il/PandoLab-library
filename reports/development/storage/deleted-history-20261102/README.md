## 원본 보존 검증

작업트리 9개, 미커밋·미추적 파일 6개와 semantic index가 같고 stash 8개가 유지됐다. workflow에서 참조하는 정확한 과거 커밋 19개를 그대로 유지했다. 기존 원본 blob/tree 56861개가 모두 로컬 객체로 존재함을 batch-check로 확인했다. 코드 tip의 실제 tree는 동일하다. 변경된 이력은 정확한 원격 이전 OID를 조건으로 10개 브랜치에 원자적으로 push했고 다시 읽어 검증했다. git fsck --full --no-reflogs가 성공했다. 전체 프로젝트 검사·GIS 재생성은 수행하지 않았다.

## 실제 정리

로컬 객체 저장소: 232,339,373 → 101,291,210바이트. 논리 감소 131,048,163바이트. 원래 pack 15개와 loose 객체를 재압축한 뒤, 변경된 이력으로 대체되고 어떤 ref·reflog·index에서도 참조하지 않는 이전 커밋 101개(25,358바이트)를 실제 삭제했다. 미확인 unreachable 객체 0개. 각 직접 삭제 파일은 단일 hardlink였고 크기·SHA-256을 재검증했다.

이력에서 제거한 경로의 blob 내용은 보호된 원본 snapshot에서도 쓰이므로 blob 전체 삭제 대상으로 삼지 않았다. 따라서 경로 이력 제거와 고유 바이트 확보는 같은 수치가 아니다. GitHub의 물리 객체 GC 및 PR/서버 캐시 제거는 서버 소유이므로 이번 push로 물리 회수됐다고 주장하지 않는다.

## 라이브러리 및 한계

PandoLab-library-data는 현재 archive/pin이 실제로 참조하는 원자료가 대부분이었다. 후보 583개 중 571개가 현행 archive에 남아 있었고 나머지 과거 P2 manifest도 현재 pin의 의존 이력이었다. 원본·현재 이력을 보존하면서 제거할 별도의 안전한 라이브러리 이력 범위를 확정하지 못해 이력 재작성하지 않았다. 라이브러리 중복 객체의 이전 정리 결과와 이번 코드 이력 정리량을 합산하지 않았다.

이번 정리는 60GB 여유 공간 목표를 달성하지 않는다. 대규모 원자료·활성 학습 산출물·현재 의존 이력은 보존했다. NTFS 할당 기준 전체 전후 차이는 사전 동일 기준 측정이 없어 확정하지 않는다. 실제 드라이브 여유 변화는 임시파일 삭제 후 별도 측정한다.
