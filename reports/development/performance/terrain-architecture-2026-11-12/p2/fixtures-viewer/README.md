# 실제 뷰어 비교용 2×2 타일 표본

NOAA ETOPO 원본의 중국 서남부 LOD5 기존 1,024 격자에 맞춘 2×2 구역을 각 타일 주위 2픽셀을 포함해 읽었다. Q1 고도와 양자화 전 높이에서 계산한 음영을 1픽셀 gutter와 함께 저장했다. 동일 영역의 1,024 타일 4개와 512 타일 16개를 WebP로 각각 인코딩해 전부 복원 검증했다.

원본 좌표에서 별도로 추출한 1,024 타일 사이 인접 경계 네 곳의 겹치는 두 열 또는 행이 바이트 단위로 같고, 512 타일 16개는 같은 영역의 1,024 원본을 gutter 포함 정확히 자른 결과와 같다. 파일별 입력·출력 해시와 좌표는 `gutter-report.json`과 `webp/manifest.json`에 있다. 이 구역만 Q1이며 전체 세계 지형을 생성하거나 운영 자료를 변경한 것이 아니다.
