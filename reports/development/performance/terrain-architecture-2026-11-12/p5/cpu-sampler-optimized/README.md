# 재사용 수치 표본 함수의 예비 측정

앱 `a63958935`의 CPU 표본 함수는 타일·색상 설정을 한 번 검증하고 출력 배열을 재사용한다. 합성 장면에서 라이트·다크, 육지·바다의 결과가 WebGL1·WebGL2와 RGB 채널 2 이내로 일치했으며, 원본 보간·색상 및 LOD 집중 검사 17개가 통과했다. 이 함수는 아직 실제 Canvas 화면 경로에 연결되지 않았다.

동일 기기의 로컬 Node 단일 프로세스에서 1026×1026 합성 타일의 표본 100,000개를 세 번 계산하는 데 21.58 / 12.22 / 12.30ms가 걸렸다. 이전 단순 API의 별도 실행 수치는 72.07 / 56.40 / 57.25ms였다. 코드 호출 및 배열 재사용 방식이 다르고 JIT·캐시를 통제하지 않았으므로 수치는 해당 API의 예비 비교일 뿐 제품 속도 향상이 아니다. 그리기, 네트워크, 실제 Viewer 및 브라우저 부하는 포함하지 않았다. 실행 원본과 환경, 소스 SHA-256은 `probe.json`에 있다.
