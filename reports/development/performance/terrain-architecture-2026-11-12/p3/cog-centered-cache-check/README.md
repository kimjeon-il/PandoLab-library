# COG 실험 캐시 상한과 현재 점유량

지역 COG 어댑터에 검증된 압축 청크 32MiB와 재인코딩된 PNG 타일 32MiB의 별도 LRU 상한을 적용했다. 한 청크의 중복 요청을 공유하고, 모든 소비자가 취소한 요청은 캐시를 오염시키지 않으며 재시도할 수 있다. 제한·퇴출 및 취소는 합성 입력 집중 검사로 확인했다.

중국 서남부 2×2 영역을 로컬 브라우저에서 모두 읽을 때 두 타일 크기 모두 범위 110회·7,153,745바이트, 청크 캐시 7,153,745바이트였다. PNG 캐시는 1024 네 장 8,958,142바이트, 512 열여섯 장 8,949,079바이트였고 퇴출은 없었다. 같은 타일을 재요청해 재사용도 확인했다. `report.json`에는 각 타일의 복원 해시와 원시 카운터가 있다. 이들은 개별 CPU 캐시의 논리 바이트이며 전체 브라우저 메모리나 GPU VRAM이 아니다.
