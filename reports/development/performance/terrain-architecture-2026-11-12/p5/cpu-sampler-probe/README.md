# 수치 고도 보간 CPU 표본

`work/gis`의 WIP `f57ce7101` 수치 표본 함수는 네 고도와 음영을 보간한 뒤 PCHIP 색상을 계산한다. 실제 Chromium WebGL1·WebGL2 합성 장면에서 동일 샘플의 CPU 결과와 RGB 차이 2 이내를 확인했다. 이 함수는 현재 Canvas 화면 렌더러에 연결되지 않았다.

로컬 Node 단일 프로세스에서 1026×1026 합성 타일의 표본 100,000개를 세 번 계산하는 데 72.07 / 56.40 / 57.25ms가 걸렸다. 원본 수치와 소스 SHA-256, 실행 환경은 `probe.json`에 있다. 이는 그리기·캐시·브라우저·실제 Viewer를 포함하지 않는 예비 측정이다. 전체 화면 성능으로 외삽하거나 현재 Canvas와의 속도 비교로 사용하지 않는다. 화면 픽셀마다 계산하는 방식을 도입하기 전에 실제 사용 경로의 성능을 검증해야 한다.
