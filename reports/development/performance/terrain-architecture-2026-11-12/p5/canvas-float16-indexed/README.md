# Float16 Canvas 높이·음영 색상 조회표

앱 `1d88e2bd5`, Chromium 151 headless/SwiftShader, 1280×800의 균일 고도·음영 단일 육지 계층 합성 시험이다. 기본 Viewer에는 연결하지 않았다. 높이 1m 및 음영 1바이트 단위로 6501×256 RGBA 색상 조회표를 사용하며 6,657,024바이트를 추가로 사용했다. 조회표 생성은 두 독립 실험에서 약 16.4·16.8ms였다.

| 측정 ms, 세 반복 | 자주 읽기 힌트 켬 | 기본 힌트 |
|---|---|---|
| Float16 getImageData | 24.8 / 25.1 / 21.7 | 87.0 / 37.6 / 34.4 |
| 기존 Float16 색상 계산 | 27.7 / 50.5 / 29.2 | 27.8 / 50.8 / 30.0 |
| 조회표 색상 계산 | 11.0 / 20.2 / 8.1 | 11.2 / 19.4 / 7.9 |
| putImageData | 4.5 / 5.1 / 4.9 | 5.8 / 3.6 / 3.3 |

선택된 높이들 × 모든 음영 값 및 라이트·다크에서 기존 CPU 팔레트와 RGB 채널당 차이 2 이내였고, 2×2 합성 지형을 4×4로 확대한 Float16 육지 표본도 RGB 최대 차이 2였다. 모든 실지형·해양·구멍·마스크·브라우저에서 오차가 제한된다는 뜻은 아니다.

렌더·조회표·읽기 반복의 실행 순서, 캐시, JIT를 통제하지 않았다. 균일 입력이며 실제 지구본, 다른 계층, 국가색, 사용자 GPU, 전송량과 Viewer 프레임 지연을 반영하지 않는다. 두 후보의 read·lookup·put을 합쳐도 기존 색상 이미지 그리기의 이전 별도 예비 결과보다 비용이 커 아직 속도 개선 또는 제품 채택 근거가 아니다. 원본 JSON은 read-frequent.json과 read-default.json에 있다.
