# 지형 구조 비교: 확보된 실험 기록

기록일: 2026-11-12. 이 문서는 현재까지 완료된 제한적 실험의 결과이며 전체 비교 실험의 완료를 뜻하지 않는다. 운영 코드 반영, main 병합, 배포 및 자료 핀 변경은 하지 않았다.

## 현재 판단

실제 뷰어와 동일 품질의 A1/B/C/D 비교가 없으므로 최종 구조나 종합 점수를 결정할 수 없다. 추가 증거가 나오기 전의 보수적인 임시 판단은 현행 유지이다. COG는 현재 GitHub raw 호스트의 브라우저 `Content-Range` 노출 조건을 충족하지 못했다. 이것이 COG 자체의 기각이나 다른 호스트에 대한 판정은 아니다. 독립 화면공간 GPU 실험도 아직 단일 표본에 국한된다. E의 선행 조건은 충족되지 않았다.

## 재현 입력과 범위

NOAA 원본 SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`; 최초 P0 앱 `ddc6063e2ebc9dee87c6ef6c49038a0fe809c234`, 자료 핀 `921d86aa3c03ffa0b3d5879ad30c9914c4d1b31a`; 실험 소스와 수정 측정기는 work/gis `f18300855`에 있다. `cog-lod3-inputs/`와 `cog-lod4-inputs/`는 COG overview의 독립 원본 기반 입력이다. 1.58GB 원본은 진행 중인 후속 실험을 위해 기존 작업 캐시에 보존했다.

적어도 A1/B/C/D의 실제 뷰어 연결과 동일 품질·환경 비교, 화면 캡처, 네트워크·메모리·안정성·PC/모바일 시나리오, 하드 게이트 및 점수 평가가 남았다. SwiftShader 결과는 실제 GPU 성능이 아니다. 측정하지 못한 항목을 0이나 통과로 기록하지 않는다.
