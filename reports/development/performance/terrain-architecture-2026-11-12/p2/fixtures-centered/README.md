# 지역 중심에 맞춘 실제 뷰어 비교 입력

중국 서남부, 태국 저지대, 네덜란드 연안의 지정 좌표가 지구본 32배 화면에 들어오도록 LOD5의 인접 1024 타일 2×2를 정렬했다. 같은 Q1·원본 기반 음영을 1024 타일 네 장과 512 타일 열여섯 장으로 각각 나타낸다. 네덜란드 카메라는 지역을 포함하면서 2×2 자료 밖으로 나가지 않도록 경도 5.5°, 위도 53°로 잡는다.

세 지역 60개 WebP는 모두 원본 RGBA와 무손실 일치한다. `verification.json`에는 각 지역의 512 타일 16개가 1024 타일의 동일 화소와 gutter를 보존하고, 별도로 계산한 1024 타일의 공유 경계 네 곳이 일치한 결과가 있다. `gutter-report.json` 및 `webp/manifest.json`은 원본·개별 파일 해시와 좌표다. 세계 전역 자료나 Viewer 비교 결과는 아니다.
