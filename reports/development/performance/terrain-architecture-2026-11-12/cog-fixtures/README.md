# COG 대표 지역 저장 형식 및 현재 호스트 예비 검증

세 1,024×1,024 Q1 표본을 EPSG:4326의 3밴드 COG로 저장했다. 블록 256과 512, Deflate를 각각 사용했다. 512×512 및 256×256 overview 입력은 동일 Float32 원본에서 해당 축척으로 별도 읽고 양자화한 자료다. 양자화한 고도나 압축된 바이트를 축소하지 않았다. 본판과 각 overview의 전 채널을 파일에서 읽어 해당 입력과 정확히 대조했다. GDAL의 COG 구조 검사(full_check)는 여섯 파일 모두 오류·경고 0건이다. 원본 결과는 `cog-validation.json`, COG 해시와 단회 생성 시간, 각 입력 해시는 `cog-report.json`에 있다.

생성 과정에서 GDAL은 `GDAL_DATA`가 정의되지 않아 `tms_NZTM2000.json`을 찾지 못한다는 경고를 한 차례 출력했다. 위 무오류·무경고는 이후 수행한 별도 COG 구조 검사의 결과이며 생성 로그의 경고와 구분한다.

| 지역 | 블록 256 (bytes) | 블록 512 (bytes) |
|---|---:|---:|
| 태국 저지대 | 1,402,759 | 1,432,011 |
| 중국 서남부 | 2,540,157 | 2,562,171 |
| 네덜란드 연안 | 627,591 | 633,275 |

이 파일에는 2개 overview가 포함되어 있어 본판만 있는 WebP 타일 실험의 용량과 직접 비교할 수 없다. 이는 저장 시제품일 뿐 COG 브라우저 디코더와 뷰어 통합, 전송 비용 및 지형 화면 성능은 아직 확인하지 않았다.

현재 배포에 사용되는 고정 GitHub raw 호스트에서 기존 DEM 타일을 대상으로 Range를 시험했다. 서버는 206, `Content-Range: bytes 0-31/68926`, 본문 32바이트를 반환했지만 `Access-Control-Expose-Headers`는 없었다. 같은 요청에 대한 Chromium 151 브라우저 JavaScript의 `Content-Range`는 `null`이었다. `range-probe.json`에 URL, 시간과 서버·브라우저 결과가 있다. 이는 현재 호스트의 브라우저 range 검증 장애이며 미래의 다른 호스트나 COG 자체에 대한 일반 판정은 아니다. 전체 파일 다운로드로 대체한 결과는 없다.
