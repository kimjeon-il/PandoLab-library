# 연속 이동 직후 수용 프레임 캡처 실패

GitHub Actions 43180024656, 앱 `2689f74ab5c759b5c8d5c8e3b045b59ab1e554b4`, 중국 서남부, A1 실험 후보, 소프트웨어 WebGL2, 실험용 192MiB다. 실험 기록과 실제로 얻은 캡처를 보존한다.

세 반복 모두 짧은 drag 장면까지 통과했다. 이후 10초 연속 이동에서는 프레임 간격 기록과 지형 LOD5 준비 판정까지 진행했지만, 수용된 화면의 캡처를 기다리는 실험 코드가 60초 제한에 도달했다. 각 실행에 콘솔 및 페이지 예외는 기록되지 않았다. 프레임 캡처를 얻지 못했으므로 이 장면과 이후 장면은 비교 통과로 취급하지 않는다.

이 증거만으로 지형 렌더러의 오류나 캡처 도구의 조건 문제 중 하나를 확정할 수 없다. 렌더 종료 지점 도달 여부와 캡처의 각 수용 조건을 기록하는 진단이 필요하다.
