# A1/B용 정렬된 대표 타일 자료

고정된 NOAA ETOPO Float32 원본에서 중국 서남부, 태국 저지대와 네덜란드 연안의 LOD5 기존 1,024 격자 경계에 정렬한 각 1,024×1,024 구역을 읽었다. 공통 Q1 높이와 양자화 전 높이에서 구한 음영을 사용하고 원본 한 픽셀을 더 읽어 각 타일의 1픽셀 gutter도 같은 방법으로 생성했다.

같은 영역마다 1,024 타일 한 장과 512 타일 네 장을 마련했다. 무손실 WebP로 저장한 15개 파일은 모두 디코딩해 원본 RGBA와 대조했다. 타일 격자, 원본 해시, 압축 전후 해시와 바이트 수는 `gutter-report.json`과 `webp/manifest.json`에 있다. 이 파일은 대표 지역 실험 입력이며 완성된 전 세계 Q1 자료나 실화면 검증 결과가 아니다.
