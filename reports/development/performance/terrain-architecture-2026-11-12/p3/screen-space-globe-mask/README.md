# physicalLand 마스크를 적용한 화면공간 지구본 기초 실험

동일한 Q1 타일 네 장과 PCHIP, 양자화 전 원본 기반 음영을 사용한 지구본 역투영 단일 화면 패스에 현재 프로젝트의 고정 `physicalLand` 원본에서 만든 지역 마스크를 적용했다. 해안 픽셀의 육지·바다 선택은 고도 부호가 아니라 마스크가 결정한다. 각 고도 이웃은 선택한 육지/해양 패스에 맞게 보정한 뒤 보간한다. `globe-1.png` 등의 실제 Chromium 캡처에서 해양색 표시를 확인했다.

마스크는 원본 벡터를 30초 DEM 격자의 중심에 무앤티앨리어싱으로 래스터화한 지역 표시 파생물이다. 실제 Viewer의 벡터 스텐실과 픽셀 동등성이 검증되지 않았고, 화면에서 해안 계단이 생길 수 있다. atlas 누락·퇴출, Viewer 통합, 실제 카메라 동등성, 날짜·테마·선택 처리는 미구현이다. 따라서 D 후보의 통과나 Viewer와의 성능 비교를 주장하지 않는다.

Windows Chromium 151, 1280×800, DPR 1, ANGLE Vulkan SwiftShader에서 세 반복 300프레임의 rAF p50/p95/p99는 100/116.6/200ms, 100/133.4/200ms, 100/116.7/183.4ms였다. 원시 간격과 타일·마스크 원본 해시는 `report.json`에 있다. rAF는 GPU 프레젠테이션 시간이나 실제 GPU 성능이 아니다.
