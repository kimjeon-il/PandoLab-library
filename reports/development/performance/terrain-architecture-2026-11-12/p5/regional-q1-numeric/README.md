# 네 지역 Q1 수치 색상 표본

앱 `7769d37e6`. 기존 외부 보고서의 중국 서남부·태국·히말라야·네덜란드 Q1 무손실 WebP 중 각 지역의 첫 1024 타일을 하나씩 선택했다. 소스 ETOPO Float32 SHA-256은 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`이며, 각 WebP 길이와 SHA 및 Chromium 복호화 픽셀 SHA를 기존 매니페스트와 대조했다.

각 타일 네 지점에서 네 높이·음영 샘플을 보간한 현재 CPU 육지 색상과 독립 PCHIP 계산을 비교해, 네 지역 모두 4개 지점의 RGB 최대 차이가 0이었다. 선택된 파일·좌표·고도·음영·원시 결과는 `probe.json`에 있다.

이는 네 타일과 16개 지점의 자료·산술 검증이며, 지형의 역사적 정확성, 바다·마스크, WebGL, Canvas 실제 화면, 이동·확대, 다크 테마, 성능 또는 새 생성기 전체 검증을 뜻하지 않는다. 원본·운영 자료 핀과 배포를 변경하지 않았다.
