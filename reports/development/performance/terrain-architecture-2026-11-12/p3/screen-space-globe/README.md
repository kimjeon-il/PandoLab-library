# 화면공간 지구본 역투영 기초 실험

실제 뷰어 A1 시험에 사용한 동일 Q1 WebP 타일 네 장과 gutter를 GPU atlas에 올린 뒤, WebGL2 화면 삼각형 한 장의 각 화소에서 지구본 역투영·고도 복호화·고도 보간·동일 PCHIP 색상 및 음영을 계산했다. 이 독립 시제품에서 화면 역투영은 구현됐지만 Viewer 카메라와 배율이 동등한지는 검증하지 않았다. 육지 마스크·바다 팔레트 합성·타일 누락/퇴출·편집·날짜·테마가 없으므로 D의 완성 또는 하드 게이트 통과가 아니다. 캡처의 바다는 육지색으로 보인다.

Windows Chromium 151, 1280×800, DPR 1, ANGLE Vulkan SwiftShader에서 각각 300개 rAF 간격을 얻은 세 반복의 p50/p95/p99는 83.4/116.7/199.9ms, 99.9/116.7/183.3ms, 83.4/116.7/183.4ms였다. `report.json`에 원시 간격과 WebGL 장치 정보가 있고 `globe-1.png`부터 `globe-3.png`까지 실제 브라우저 캡처다. 이 시제품의 프레임 스케줄링 수치로 실제 GPU 성능이나 GitHub Actions Viewer와의 상대 성능을 판단할 수 없다.
