# 네 지역 Q1 육지 색상 확장 표본

앱 `656e1bae6`. 이전 외부 저장소의 중국 서남부·태국·히말라야·네덜란드 Q1 1024 WebP 중 각 지역 첫 타일 1개를 선택했다. ETOPO Float32 원본 SHA-256 `8630abc401cc6bdd30b507a68d3eb9eda5b65f5636f7199e4b1eefd476b5a9e2`, 각 저장 WebP 해시와 Chromium 복호화 픽셀 해시를 기존 매니페스트와 대조했다.

타일당 고정 4지점과 결정적 난수 256지점, 각 라이트·다크 2개씩 총 2,080개의 CPU 육지 색상을 별도 PCHIP 계산과 비교했고 각 RGB 최대 차이는 모두 0이었다. 좌표·고도·음영·테마·픽셀 해시와 개별 결과는 `probe.json`에 보존한다.

이는 기존 실험 자료에 대한 CPU 수치 함수 표본이며 현재 Viewer의 화면, 지구본, 바다·육지 마스크, WebGL, 확대·이동, 타일 요청 및 성능이나 새 생성기 전체의 검증이 아니다. 원본·운영 자료 핀과 배포를 변경하지 않았다.
